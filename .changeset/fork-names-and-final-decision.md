A run after an interrupted one starts cleanly when the earlier run left a fork branch behind. `isolated()` and `tournament()` skip a branch name that already exists and take another, as `dag()` does, and the old branch stays as it was so you can still recover its work. A reviewer's or writer's reply can show code, a JSON example or a braced aside before its answer: the decision is the last JSON object in the reply with a `status` of `pass` or `revise` and a non-empty `summary`, so such a reply reads as its final answer.
