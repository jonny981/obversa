# @obversa/obversa

Install every public Obversa package with one dependency.

```bash
npm install @obversa/obversa
```

The individual packages stay separately importable. Import the runtime,
engines, memory adapters, surfaces, notifications, or ready-made workflows
from their own package names.

This package has no runtime API of its own.

Read the package groups at [docs.obversa.ai/packages/obversa](https://docs.obversa.ai/packages/obversa).
