---
title: "Graph executor"
description: "Run a stored graph one recorded decision at a time: check the engines first, pause on a record when a check fails, resume from that exact record, and recover after a process stops."
---

The graph executor turns a stored run into work. Your graph makes the
decisions; the executor records each one before any node runs, runs each
node inside the safe attempt lifecycle, and records what came back. When
the plan carries a preflight policy it checks every engine seat before the
first dispatch, and a failed check pauses the run on a record you resume
from later.

## The file

This file stores a one-node graph, runs the executor against a scripted
local engine that is not ready, sees the run pause before any dispatch,
makes the engine ready, and resumes with the exact pause event the first
run returned. The engine and its bindings are in
`examples/preflight-host.mjs`.

```ts
import assert from 'node:assert/strict';
import { existsSync } from 'node:fs';
import { mkdtemp, readFile, realpath, rm, writeFile } from 'node:fs/promises';
import { tmpdir } from 'node:os';
import { join } from 'node:path';

import {
  compileGraph,
  createGraphExecutor,
  dagGraphType,
  loadRunDefinition,
  persistRunDefinition,
  readRunPreflight,
  resolveGraphPlan,
  type DagDefinition,
  type ExecutionTarget,
  type RunStoragePolicy,
} from '@obversa/runtime';
import { createLocalRunStorage } from '@obversa/runtime/storage/local';
import { bindRun } from './preflight-host.mjs';

const target = {
  adapter: 'scripted-local',
  provider: 'local',
  modelFamily: 'scripted',
  model: 'offline-check',
  tools: [],
} as const satisfies ExecutionTarget;

const definition = {
  id: 'preflight-executor',
  definitionVersion: 1,
  data: {
    globalConcurrency: 1,
    keyedConcurrency: {},
    stopOnError: true,
    retryCapPerNode: 0,
  },
  nodes: [{
    id: 'check',
    data: {
      kind: 'required',
      key: null,
      lane: { id: 'local', requested: target, knownSubstitutions: [] },
    },
  }],
  edges: [],
} as const satisfies DagDefinition;

const storagePolicy = {
  schemaVersion: 1,
  maxEventPayloadBytes: 64_000,
  maxAppendBatchBytes: 128_000,
  maxArtifactBytes: 1_000_000,
  maxTotalArtifactBytesPerRun: 4_000_000,
  retention: 'until-run-delete',
  sensitiveContent: {
    marked: 'reject',
    exact: 'reject',
    freeText: 'redact-before-hash',
  },
} as const satisfies RunStoragePolicy;

const temporaryRoot = await realpath(await mkdtemp(join(tmpdir(), 'obversa-preflight-executor-')));
const controlFile = join(temporaryRoot, 'control.txt');
const runId = 'preflight-executor-run';
const callsFile = join(temporaryRoot, 'engine-calls.log');
let report: Record<string, unknown> | undefined;

try {
  await writeFile(controlFile, 'not-ready\n');
  await writeFile(callsFile, '');
  const graph = compileGraph(dagGraphType, definition);
  const packageIdentity = {
    source: 'npm:@example/preflight-executor',
    version: '1.0.0',
    digest: 'sha256:4444444444444444444444444444444444444444444444444444444444444444',
  } as const;
  const plan = resolveGraphPlan(graph.describe(), {
    package: packageIdentity,
    admission: { package: packageIdentity, permissions: [] },
    executionLanes: [{ id: 'local', effective: target }],
    preflight: {
      timeoutMs: 2_000,
      lanes: [{ laneId: 'local', live: 'required', unsupportedStatic: 'block' }],
    },
  });
  const storage = createLocalRunStorage({
    directory: join(temporaryRoot, 'storage'),
    namespace: 'preflight-executor-example',
    policy: storagePolicy,
  });
  await persistRunDefinition(storage, {
    runId,
    eventId: 'preflight-executor-started',
    timestamp: new Date().toISOString(),
    graphDefinition: graph.definition,
    resolvedPlan: plan,
    resolvedInputs: { controlFile, callsFile },
    workspaceBinding: null,
    hostBinding: null,
  });

  const loaded = await loadRunDefinition(storage, runId);
  const makeExecutor = async () => createGraphExecutor({
    ...await bindRun({
      definition: loaded.record.payload.definition,
      scratchDirectory: temporaryRoot,
    }),
    runId,
    storage,
    preflightScratchDirectory: temporaryRoot,
  });

  const paused = await (await makeExecutor()).run(new AbortController().signal);
  if (paused.kind !== 'pause' || !('preflightEventId' in paused)) {
    throw new Error(`Expected a preflight pause, received ${JSON.stringify(paused)}.`);
  }
  assert.equal(paused.code, 'PREFLIGHT_PAUSED');
  assert.equal((await readRunPreflight(storage, runId)).phase, 'paused');

  let dispatchesBeforeResume = 0;
  for await (const event of storage.eventStore.read({
    namespace: storage.record.namespace,
    streamId: runId,
  })) {
    if (event.type === 'graph:node-dispatched') dispatchesBeforeResume += 1;
  }
  assert.equal(dispatchesBeforeResume, 0);

  await writeFile(controlFile, 'ready\n');
  const completed = await (await makeExecutor()).resume(
    { preflightEventId: paused.preflightEventId },
    new AbortController().signal,
  );
  if (completed.kind !== 'complete') {
    throw new Error(`Expected completion, received ${JSON.stringify(completed)}.`);
  }
  assert.deepEqual(completed.output, { nodes: { check: { checked: 'offline' } } });
  const finalPreflight = await readRunPreflight(storage, runId);
  assert.equal(finalPreflight.phase, 'admitted');
  assert.equal(finalPreflight.resumedPreflightEventId, paused.preflightEventId);
  const calls = (await readFile(callsFile, 'utf8')).trim().split('\n').filter(Boolean);
  assert.deepEqual(calls, ['static', 'live:not-ready', 'static', 'live:ready', 'ordinary']);

  report = {
    pause: { phase: 'paused', code: paused.code, dispatches: dispatchesBeforeResume },
    resume: {
      usedReturnedToken: finalPreflight.resumedPreflightEventId === paused.preflightEventId,
      phase: finalPreflight.phase,
      result: completed.kind,
      output: completed.output,
    },
    calls,
  };
} finally {
  await rm(temporaryRoot, { recursive: true, force: true });
}

console.log(JSON.stringify({
  ...report,
  temporaryDirectoryRemoved: !existsSync(temporaryRoot),
}, null, 2));
```

## How a dispatch runs

1. The executor loads the run definition and the frozen plan from storage
   and checks that the supplied graph matches them.
2. When the plan carries a preflight policy, it checks every engine seat:
   a static check of the seat's identity, and where the lane requires it,
   one tool-free live call. A failed check pauses the run with
   `PREFLIGHT_PAUSED` before anything is dispatched.
3. It folds the run's recorded events into graph state and asks the graph
   for its next command.
4. It records the whole dispatch decision, then `node-attempt-started`
   immediately before each node starts.
5. It runs each node through the safe attempt lifecycle and records
   `node-completed`, `node-paused` or `node-failed`, then asks the graph
   again.

Node behaviour is keyed by node id: a data-only node gets a function, an
engine-backed node gets a prompt builder that receives that dispatch's
typed input. The node uses the lane in the stored plan, and the engine
binding joins that plan target to the full engine identity.

## Fallback and what a failure retires

The host chooses the lane order once. The executor tries the effective
target and at most one live fallback. Only a failure that means the lane is
dead can move to the fallback; a rate limit, a timeout, a policy pause or a
denied action does not run again elsewhere.

Each dead-lane event records the selected identity and the engine's
reported identity when available. What the failure retires depends on what
it proves: bad credentials retire every model on that adapter and
provider, because the credential is theirs; a missing model, exhausted
credit or an exhausted quota retire that provider and model; a missing
command-line tool or an invalid configuration retire the adapter; a rate
limit or a transport error retire nothing. The retirement is keyed on the
seat that was selected, never on an identity the engine claimed in its
output. An old auth record with no provider recovers one from its lane,
and an ambiguous recovery refuses before any work with
`ENGINE_IDENTITY_UNRESOLVED`. Later dispatches skip whatever was retired.
During a run, if every declared target of a lane is dead, the executor
records `ENGINE_UNAVAILABLE` as a normal node failure so the graph can
retry, fail or recover in its usual way. Before the first step, when the
plan carries a preflight policy and every target of a lane is excluded or
blocked by its checks, the run ends instead with `PREFLIGHT_FAILED`: a
terminal failure written to the record as `preflight:failed`, returned by
`run()` as `{ kind: 'fail', code: 'PREFLIGHT_FAILED' }`, and still terminal
on a fresh executor. Nothing was dispatched, and there is no pause to
resume from.

An action-policy wait records `node-paused` with its reason and request.
A denied action records `node-failed` with `DENIED`; an aborted attempt,
`ABORTED`. A result too large for the event stream records a small
`node-failed` with `RESULT_TOO_LARGE`, so the dispatch never stays in
flight.

## Engine identity records

Every engine call records a `graph:engine-attempt-recorded` event before
fallback routing or the node's result: node id, position, sequence,
requested identity and reported effective identity. The sequence starts at
1 for each position and continues across fallback calls and resume.
Recovery of a started, unfinished engine node adds a record with both
identities null, which records uncertainty rather than a count of calls.

A receipt that cannot be saved makes `run()` reject and stops the affected
attempt before fallback or completion. Other attempts in the same batch can
continue. The records describe what the bound engine reported; they do not
see inside an adapter.

## Resume after a process stops

A fresh executor returns `waiting` when a dispatch has no result, with the
open positions. Call `resume` with one exact position, only after the
earlier process has stopped; the executor does not lock the run between
processes. If two dispatches were open, the result after the first resume
is `waiting` again with the sibling's position.

- **Node code did not start.** The executor runs the attempt at its
  recorded position.
- **A retry is safe.** With `retrySafe: true` saved in the start record,
  resume records `node-resumed` and runs the same attempt again.
- **The result is not known.** With `retrySafe` false, resume records a
  pause with a `reconcile-attempt` request naming the attempt, and does not
  call node code.
- **The node is paused.** Resume records `node-resumed` and offers the same
  attempt again.

For a preflight pause, call `resume` with `{ preflightEventId }` from the
pause the first run returned. The static checks run again, live receipts
that still apply are reused, and a stale id is refused with
`RESUME_EVENT_MISMATCH` naming both ids. The saved `retrySafe` value and
the saved plan govern recovery; a change in the live binding does not
rewrite an earlier record.

## When a check was interrupted

A live check is an engine call, and the process can die in the middle of
it. The record then holds an open probe, and a fresh executor's `run()`
fails with `PROTOCOL`, naming the probe and telling you what to do: verify
that the old worker and its engine process are gone, then call
`interruptRunPreflight(storage, runId)`. It closes the open probe as
`interrupted` with one expected-revision append, writes a preflight pause,
and returns that pause, whose `preflightEventId` the next resume takes; it
returns `null` when no probe is open, and the existing pause when one is
already recorded. It never retries and never calls an engine.

Call it only when you own the run and have verified the worker is gone. If
the old engine call is still alive, the record says interrupted while the
call keeps spending, and whatever that call would have proved is lost.

## Gotchas

- **A check is not a run.** The live check is one tool-free call with no
  workspace. It proves the seat answers; it does no work.
- **An engine without `admit` is `unsupported`,** and the lane's
  `unsupportedStatic` policy says whether that blocks the run or is allowed.
  Unsupported is never a success receipt.
- **Checks need a scratch directory, and the constructor is what refuses.**
  When the plan carries a preflight policy, `createGraphExecutor` requires
  `preflightScratchDirectory`, an absolute, real, normalized path. The
  option is optional in the type, so `await createGraphExecutor(...)`
  rejects with a `GraphExecutionError` whose code is
  `INVALID_PREFLIGHT_CONFIG` when the plan needs it and it is missing or
  malformed. It is the construction that rejects, not `run()`, so the
  handling goes around the construction. The policy itself must name every
  resolved lane once and keep `timeoutMs` between 1 and 2147483647
  milliseconds, or `resolveGraphPlan` rejects it before the plan is frozen.
- **Usage from checks is separate from usage from nodes,** and missing
  usage is not zero.

## Source

The file is `examples/preflight-executor.ts`, with its engine and bindings
in `examples/preflight-host.mjs`. The executor's options and result types
are exported by `@obversa/runtime`; `readRunPreflight` reads the preflight
record of a stored run without touching an engine, and
`interruptRunPreflight` closes a check the process died in the middle of.
