Pick LangGraph to build the agent itself, and Obversa to run the coding
agents you already have as a team. LangGraph is a low-level graph runtime
for stateful agents in Python and JavaScript: in its own words, "a
low-level orchestration framework and runtime for building, managing, and
deploying long-running, stateful agents." Obversa is a TypeScript library
that runs Claude Code, Codex and their kin as a team, with a review that
fails a step and runs it again, a person who decides, and a record of every
step.

## What each is for

| The job | LangGraph | Obversa |
| --- | --- | --- |
| Unit of work | A node: a function over shared state. | A stage: an engine call, a command, a panel or a person, with the files it may write. |
| The workers | Model calls you write inside nodes. | Engines such as Claude Code, Codex, Grok and OpenCode, a fresh process per call, or an API engine. |
| A review that fails a step | A conditional edge or a jump to an earlier node, which you write. | Built in: the findings go to the stage that owns the fix, which runs again, up to a limit you set. |
| A person deciding | `interrupt()` in a node; a client resumes with the answer. | A person role. The run pauses on the question, and the answer arrives through the callbacks client. |
| More than one provider | Different nodes can call different providers; you write the client each time. | Each role names its engine. A review seat from another provider is one line. |
| A run that survives a crash | The checkpointer saves state at every step, in Postgres or SQLite. | A run records to a file and carries on from it with `resume: true`; the supervised runner restarts a killed run from its own record. |
| Where it runs | A library you host, with a hosted platform on offer. | A library, no server. |
| Languages | Python, and JavaScript with TypeScript. | TypeScript. |

## Where each wins

- **LangGraph, when you're writing the agent's inner loop.** A graph of your
  own nodes over shared state, with the checkpointer keeping it in Postgres
  or SQLite.
- **LangGraph, when your team writes Python.**
- **Obversa, when the agents already exist as tools on your machine** and
  the job is the process around them: who writes, who reviews, who ships.
- **Obversa, when the review and the person should be declared, not
  written** as control flow each time, and the whole team should read as
  one file with the record beside it.
- **Obversa, when a second opinion should come from another provider**
  without writing a client.

## Together

A LangGraph app is a program, and an Obversa stage can run a program as a
command: the exit code decides, and a red run carries the output to the
stage that owns the fix:

```ts examples/teams/writer-reviewer-pair.ts (excerpt) {2}
      stage('test', {
        run: ['node', '--test', 'test/add.test.mjs'],
        desc: 'Run the test command against the written files.',
        gate: 'The test command exits 0.',
        sendsBackTo: 'write',
      }),
```

Put your LangGraph agent where the test command is, and the team around it
still has its reviewers, its person and its record.
