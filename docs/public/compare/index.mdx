Choose how you want to organise the work: through an app, inside an agent,
or in a workflow you write and run.

Obversa puts the process in a TypeScript file. Use the agent CLIs you
already have signed in. Send failed tests and review notes back to the
writer. Let a judge decide whether another round helps, and ask a person
where the work needs their decision. The run keeps its record in a plain
file, with no server to deploy.

The table links to each product's documentation. It describes the paths
those docs show; it is not a list of everything each tool can do.

person's decision](/patterns/approval). The [complete workflows](/workflows)
combine those patterns for editorial work, research, support and software
delivery.
