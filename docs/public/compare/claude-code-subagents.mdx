Pick subagents for one Claude Code session's work; pick Obversa when the
reviewer has to be someone else and a person still ships. In
Claude Code's own words, subagents are "specialized AI assistants that
handle specific types of tasks": a markdown file with a name, a
description, its tools and its model, running inside your Claude Code
session, with its transcript kept on disk so it can be resumed. Obversa is
a TypeScript library that runs Claude Code and other coding agents as a
team, with a reviewer from a different model family, a person who decides,
and a record you can read after the run. Both can be true at once: a
subagent can review, and Obversa is for when the reviewer has to be someone
else.

## What each is for

| The job | Claude Code subagents | Obversa |
| --- | --- | --- |
| Unit of work | A subagent: a prompt, tools and a model, invoked from the session. | A stage: an engine call, a command, a panel or a person, with the files it may write. |
| The workers | Claude models, inside Claude Code. | Engines such as Claude Code, Codex, Grok and OpenCode, a fresh process per call, or an API engine. |
| A review that fails a step | A subagent can be asked to review; what happens next is direction you give. | Built in: the findings go to the stage that owns the fix, which runs again, up to a limit you set. |
| A person deciding | Permission prompts at tool calls, and plan mode. | A person role. The run pauses on the question, and the answer arrives through the callbacks client. |
| More than one provider | The Claude family. | Claude, OpenAI, xAI and OpenCode's providers, one per role. |
| A run that survives a crash | Transcripts on disk; a subagent can be resumed. | A run records to a file and carries on from it with `resume: true`; the supervised runner restarts a killed run from its own record. |
| Where it runs | Inside Claude Code, on your machine. | A library, no server, on your machine. |
| How it is written | Markdown with front matter. | TypeScript. |

## Where each wins

- **Subagents, when you're already in Claude Code** and the task is one
  session's work.
- **Subagents, when the permission checks at every tool call** are the
  safety net you want, with nothing more to install.
- **Subagents, when one model family is enough.**
- **Obversa, when the review should come from a different family** than the
  one that wrote the work; `workflow()` refuses a reviewer from the writer's
  family before any model runs.
- **Obversa, when the process should be a file under version control**,
  reviews included, with the run's record beside it.
- **Obversa, when the last word should be a person's**, asked as a step.

## Together

Obversa runs Claude Code as a seat, so the session you already use becomes
one role in a team, and a different model reads its work:

```ts examples/teams/writer-reviewer-pair.ts (excerpt) {2-3}
    roles: {
      write: engines.claude('claude-sonnet-4-5'),
      review: [engines.codex('gpt-5.6-luna')],
    },
```

The Claude seat is the same Claude Code you run by hand, started fresh for
each call with the stage's brief.
