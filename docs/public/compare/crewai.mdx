Pick CrewAI to describe agents by role, goal and backstory in Python and
let a crew work through tasks; pick Obversa to run the coding tools you
already have as a team. CrewAI, in its own words, is "the leading
open-source framework for orchestrating autonomous AI agents and building
complex workflows." Obversa is a TypeScript library that runs Claude Code,
Codex and their kin as a team, each call in a fresh process allowed to write
only the files the stage declared, with a review that runs the writer again
and a person who signs off.

## What each is for

| The job | CrewAI | Obversa |
| --- | --- | --- |
| Unit of work | An agent with a task: a description, an expected output and the agent that does it. | A stage: an engine call, a command, a panel or a person, with the files it may write. |
| The workers | Model calls the framework makes for each agent. | Engines such as Claude Code, Codex, Grok and OpenCode, a fresh process per call, or an API engine. |
| A review that fails a step | A task guardrail retries the same task when its output fails a check. Routing to an earlier step is flow logic you write. | Built in: the findings go to the stage that owns the fix, which runs again, up to a limit you set. |
| A person deciding | `human_input=True` on a task, or a webhook flow that pauses the run until a decision comes back. | A person role. The run pauses on the question, and the answer arrives through the callbacks client. |
| More than one provider | Each agent takes its own model; many providers supported. | Each role names its engine. A review seat from another provider is one line. |
| A run that survives a crash | Checkpointing captures the crew's state, memory and event history, so a run can be restored. | A run records to a file and carries on from it with `resume: true`; the supervised runner restarts a killed run from its own record. |
| Where it runs | A library, with a paid hosted platform on offer. | A library, no server. |
| Languages | Python. | TypeScript. |

## Where each wins

- **CrewAI, when you want agents written as roles with goals** and the
  framework to make the model calls.
- **CrewAI, when your team writes Python.**
- **Obversa, when the agents are coding tools you already have**, and each
  call should run in a fresh process, allowed to write only the files the
  stage declared.
- **Obversa, when a failed review must go to the stage that owns the fix**,
  with the findings, instead of retrying the same task.
- **Obversa, when the whole team should be one TypeScript file** with the
  record beside it.

## Together

A crew is a program, and an Obversa stage can run a program as a command:
the exit code decides, and a red run carries the output to the stage that
owns the fix:

```ts examples/teams/writer-reviewer-pair.ts (excerpt) {2}
      stage('test', {
        run: ['node', '--test', 'test/add.test.mjs'],
        desc: 'Run the test command against the written files.',
        gate: 'The test command exits 0.',
        sendsBackTo: 'write',
      }),
```

Put the crew where the test command is, and the reviewers, the person and
the record stay around it.
