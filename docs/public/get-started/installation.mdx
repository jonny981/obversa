Obversa is a library you import: add the packages to a Node project, write
a TypeScript file, and run it. There's nothing to clone, no service to run
and no account to sign into.

## Prerequisites

You need:

- **Node.js 22.12 or later.**
- **npm or pnpm.**
- **A coding agent signed in**, such as Claude Code or Codex, for a run that
  calls a real model. The file below runs without one.

Every Obversa package is an ES module, so the project needs
`"type": "module"` in its `package.json`, and `tsx` runs a TypeScript file
directly:

```bash Terminal
npm pkg set type=module
npm install --save-dev tsx
```

## Install

Install the bundle:

<CodeGroup>

```bash npm
npm install @obversa/obversa
```

```bash pnpm
pnpm add @obversa/obversa
```

</CodeGroup>

The bundle installs every package except the Jev engine, which installs on
its own. It has no API of its own, so import each tool from its own package.
[Plugins and tools](/packages) lists what each engine needs on your machine.

## The smallest file

One agent job, with a scripted engine in place of a model:

```ts examples/one-agent-job.ts
import { agentJob, run } from '@obversa/runtime';
import { MockEngine } from '@obversa/runtime/testing';

const engine = new MockEngine(() => 'ready');

const job = agentJob({
  label: 'prepare-item',
  engine: 'offline',
  prompt: 'Prepare the item.',
});

const result = await run(job, {
  engine: 'offline',
  engines: { offline: engine },
});

console.log(result.outcome.status);
```

`run()` hands the prompt to the engine named `offline`, which is the
`MockEngine` you passed in, and returns the job's outcome. Swap the scripted
engine for a plugin such as `claude` from `@obversa/engine-claude-cli`, and
the same job runs a real model.

## Run it

Save the file as `one-agent-job.ts` and run it:

```bash Terminal
npx tsx one-agent-job.ts
```

```text Output
pass
```

The job passed: the engine answered, and the run ended with that outcome.
