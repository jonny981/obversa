Obversa is a set of packages you import. There's nothing to clone and no
service to run.

## Requirements

You need Node.js 22.12 or later. Every Obversa package is an ES module and a
workflow is a TypeScript file, so your project needs `"type": "module"` in
its `package.json` and `tsx` to run the file:

```bash
npm pkg set type=module
npm install --save-dev tsx
```

Node can also run the file without `tsx`. From Node 22.12, pass
`--experimental-strip-types`. From Node 22.18, you don't need the flag.

## Add it to your project

```bash
npm install @obversa/obversa
```

The bundle installs every package except Jev: the runtime and runner, the
shared contracts, the ready-made workflows, the surfaces, six engine
plugins, three memory adapters and the webhook notifier. It has no API of
its own, so import each tool from its own package. The CLI engines also need
their command line tool installed and signed in.

[Jev](/packages/engine-jev-api) installs separately:

```bash
npm install @obversa/engine-jev-api
```

[Plugins and tools](/plugins) lists what each engine needs.

## Write a file

A workflow is a TypeScript file that imports the runtime and describes the
work. There's no configuration file, no scaffolding step and no directory
layout to adopt.

```ts
/**
 * The first file a reader writes.
 *
 * Two steps and a dependency between them, in the shape every larger workflow
 * uses: nodes with names, each saying what it is for, and `needs` saying what
 * has to happen first. It runs offline with no model, so the shape is the only
 * thing on show.
 */
import { dag, fnJob, run, type Outcome } from '@obversa/runtime';

const draft = fnJob('draft', async (): Promise<Outcome> => ({
  status: 'pass',
  summary: 'wrote the first version',
}));

const review = fnJob('review', async (ctx): Promise<Outcome> => ({
  status: 'pass',
  summary: `read ${ctx.lastOutcome?.summary ?? 'the draft'}`,
}));

export const writeAndReview = dag({
  name: 'write-and-review',
  nodes: {
    draft: { desc: 'Write the first version', job: draft },
    review: { desc: 'Read it and say whether it stands', needs: 'draft', job: review },
  },
});

const result = await run(writeAndReview);
console.log(JSON.stringify({ status: result.outcome.status }, null, 2));

if (result.outcome.status !== 'pass') process.exitCode = 1;
```

Save it as `write-and-review.ts` and run `npx tsx write-and-review.ts`.
