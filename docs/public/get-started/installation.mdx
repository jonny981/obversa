Obversa is a set of packages you import. You do not clone anything, and there
is no service to stand up.

## Requirements

Node.js 22.12 or later. Nothing else.

## Add it to your project

```bash
npm install @obversa/runtime
```

That is the runtime and its public contract. Add an engine when you want a
real model to do the work, and a memory adapter when you want the work
remembered:

```bash
npm install @obversa/engine-claude-cli @obversa/memory-simple
```

Every package is on the [packages](/packages/runtime) pages, with what each
one is for.

## Write a file

A workflow is a TypeScript file that imports the runtime and describes the
work. Nothing else is involved: no configuration file, no scaffolding step,
no directory layout to adopt.

```ts
import { fnJob, pipeline, run, type Outcome } from '@obversa/runtime';

const draft = fnJob('draft', async (): Promise<Outcome> => ({
  status: 'pass',
  summary: 'wrote the first version',
}));

const review = fnJob('review', async (): Promise<Outcome> => ({
  status: 'pass',
  summary: 'reads correctly',
}));

const result = await run(pipeline('write-and-review', [
  { name: 'draft', job: draft },
  { name: 'review', job: review },
]));

console.log(result.outcome.status);
```

Run it the way you run any TypeScript file in your project.
