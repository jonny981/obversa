---
title: "A review panel with a threshold"
description: "One model implements, several review at the same time, and the change passes when enough of them accept."
---

When one opinion isn't enough, ask several at once. This file names a
Claude seat that implements the brief and a panel of two reviewers from
two other model families. Node runs the test, then both reviewers judge
the change at the same time. The change passes when at least `agree` of
them accept. A panel below that sends the work back to the implementer,
once.

```bash
npm install @obversa/obversa
```

Set up the project as [Installation](/get-started/installation) describes.

## The file

The third seat runs through the OpenCode command line tool, `opencode`.
Give that seat an absolute command path. The Claude and Codex adapters find
their own commands, but OpenCode's doesn't.
`resolveCommandExecutable('opencode')` finds the command on your `PATH`
when the file runs, then passes that path to `opencode`.

```ts
import { claude } from '@obversa/engine-claude-cli';
import { codex } from '@obversa/engine-codex-cli';
import { resolveCommandExecutable } from '@obversa/core/command';
import { opencode } from '@obversa/engine-opencode-cli';
import { run } from '@obversa/runtime';
import { briefFromFile, stage, workflow, type TeamSeat } from '@obversa/runtime';

interface ThresholdPanelEngines {
  readonly claude: (model: string) => TeamSeat;
  readonly codex: (model: string) => TeamSeat;
  readonly opencode: (model: string) => TeamSeat;
}

const realEngines: ThresholdPanelEngines = {
  claude,
  codex,
  opencode: (model) => opencode(model, {
    executable: resolveCommandExecutable('opencode'),
  }),
};

function createThresholdPanel(engines: ThresholdPanelEngines = realEngines) {
  return workflow('threshold-panel', {
    brief: briefFromFile('briefs/double.md'),
    options: { timeout: '10m' },

    roles: {
      implement: engines.claude('claude-sonnet-4-5'),
      review: [
        engines.codex('gpt-5.6-luna'),
        engines.opencode('opencode/big-pickle'),
      ],
    },

    stages: [
      stage('implement', {
        agent: 'implement',
        writes: ['src/double.mjs', 'test/double.test.mjs'],
        desc: 'Write the function and its test from the brief.',
        gate: 'The files named in the brief exist in the workspace.',
        retry: 1,
      }),
      stage('test', {
        run: ['node', '--test', 'test/double.test.mjs'],
        desc: 'Run the test command against the written files.',
        gate: 'The test command exits 0.',
        sendsBackTo: 'implement',
      }),
      stage('review', {
        panel: 'review',
        agree: 1,
        desc: 'Have both reviewers read the change and count the acceptances.',
        gate: 'At least one reviewer has accepted.',
        sendsBackTo: 'implement',
      }),
    ],
  });
}

const result = await run(createThresholdPanel());
console.log(JSON.stringify(result.outcome, null, 2));
```

## What a run printed

From one real run of this file. The Codex reviewer accepted. The OpenCode
seat returned no decision. The panel recorded an engine error for it
rather than a rejection, and sent nothing back to the implementer on its
account. With `agree: 1` the change passed on the one acceptance. Set
`agree` to two and the same run would have paused at the panel instead,
because an error isn't an acceptance.

## The team's shape

| stage | does | done when |
| --- | --- | --- |
| implement | Write the function and its test from the brief. | The files named in the brief exist in the workspace. |
| test | Run the test command against the written files. | The test command exits 0. |
| review | Have both reviewers read the change and count the acceptances. | At least one reviewer has accepted. |

The reviewers run at the same time, one job each. `agree` is a whole
number from one to the number of reviewers, and the default is all of
them. A panel below it is a revision request aimed at `implement`, bounded
by that stage's `retry`.

Keep `agree` at the number of reviewers when one dissent must send the work
back. Below that, the change can pass despite a dissent. The dissent is
still on the record.

Pick the implementer and every reviewer from different model families. Two
reviewers from one family would be one opinion counted twice. The team
refuses the shape before any model runs.

A reviewer's decision is its reply. The panel reads the first JSON object
in each one. A reply with no decision is asked for once more. After that it
counts as an engine error, not a rejection.
