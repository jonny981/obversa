---
title: "A review panel with a threshold"
description: "One model implements, several review at the same time, and the change passes when enough of them accept."
---

When one opinion is not enough, ask several at once. This file names a
Claude seat that implements the brief and a panel of two reviewers from
two other model families; Node runs the test, then both reviewers read
the change at the same time. The change passes when at least `agree` of
them accept. A panel below that sends the work back to the implementer,
once.

```bash
npm install @obversa/runtime @obversa/teams @obversa/engine-claude-cli @obversa/engine-codex @obversa/engine-opencode-cli
```

## The file

The third seat runs through the OpenCode command line tool named `opencode`.
Put that command on your `PATH` before running the file.

```ts
import { claude } from '@obversa/engine-claude-cli';
import { codex } from '@obversa/engine-codex';
import { opencode } from '@obversa/engine-opencode-cli';
import { pathToFileURL } from 'node:url';
import { run } from '@obversa/runtime';
import { fromFile, stage, workflow, type TeamSeat } from '@obversa/teams';

export interface ThresholdPanelEngines {
  readonly claude: (model: string) => TeamSeat;
  readonly codex: (model: string) => TeamSeat;
  readonly opencode: (model: string) => TeamSeat;
}

const realEngines: ThresholdPanelEngines = {
  claude,
  codex,
  opencode: (model) => opencode(model, { executable: 'opencode' }),
};

export function createThresholdPanel(engines: ThresholdPanelEngines = realEngines) {
  return workflow('threshold-panel', {
    brief: fromFile('briefs/double.md'),
    options: { timeout: '10m' },

    roles: {
      implement: engines.claude('claude-sonnet-4-5'),
      review: [
        engines.codex('gpt-5.6-luna'),
        engines.opencode('opencode/big-pickle'),
      ],
    },

    stages: [
      stage('implement', {
        agent: 'implement',
        writes: ['src/double.mjs', 'test/double.test.mjs'],
        desc: 'Write the function and its test from the brief.',
        gate: 'The files named in the brief exist in the workspace.',
        retry: 1,
      }),
      stage('test', {
        run: ['node', '--test', 'test/double.test.mjs'],
        desc: 'Run the test command against the written files.',
        gate: 'The test command exits 0.',
        sendsBackTo: 'implement',
      }),
      stage('review', {
        panel: 'review',
        agree: 1,
        desc: 'Have both reviewers read the change and count the acceptances.',
        gate: 'At least one reviewer has accepted.',
        sendsBackTo: 'implement',
      }),
    ],
  });
}

if (process.argv[1] && import.meta.url === pathToFileURL(process.argv[1]).href) {
  const result = await run(createThresholdPanel());
  console.log(JSON.stringify(result.outcome, null, 2));
}
```

the panel records an engine error for it rather than a rejection, and
sends nothing back to the implementer on its account. With `agree: 1` the
change passed on the one acceptance. Set `agree` to two and the same run

## The team's shape

| stage | does | done when |
| --- | --- | --- |
| implement | Write the function and its test from the brief. | The files named in the brief exist in the workspace. |
| test | Run the test command against the written files. | The test command exits 0. |
| review | Have both reviewers read the change and count the acceptances. | At least one reviewer has accepted. |

The reviewers run at the same time, one job each. `agree` is a whole
number from one to the number of reviewers; the default is all of them. A
panel below it is a revision request aimed at `implement`, bounded by
that stage's `retry`.

## Gotchas

- **The implementer and every reviewer are different families.** Two
  reviewers from one family would be one opinion counted twice; the team
  refuses the shape before any model runs.
- **A reviewer's decision is its file first.** Each reviewer writes
  `reviews/<name>.json`; the panel reads that file when the reviewer wrote
  it this turn, then the first decision object in the reply. A reply with
  no decision in either is asked for once more, then counts as an engine
  error, not a rejection.
- **`agree` equal to the reviewer count means unanimity.** Set it lower
  and one dissent does not send the work back; the dissent is still on the
  record.
- **The OpenCode seat needs a command.** `opencode(model, { executable: 'opencode' })`
  uses the command line tool available on your `PATH`.
