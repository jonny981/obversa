The examples that ship with this release cover work outside software
delivery: grooming a backlog, reviewing a contract against a playbook, and
translating with a glossary.

The next set covers the shapes that need the features on these coming-soon
pages. Workflows that stop for an answer and resume when it arrives, without
a process waiting in between. A workflow that leans on fast decisions,
where research and classification are typed calls, and the sizing and the
sending stay with a person.
