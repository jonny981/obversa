**Coming soon.** Not in this release. This page says what the feature is,
so that the shape is public before the code is.
</Note>

Build your own view of a run against a published contract, instead of
holding the run and folding its events yourself. A run already knows
everything worth watching: which step is running, what each one decided,
what a reviewer found, what the whole thing has spent. Today a host reads
that by holding the run and folding the events itself.

An observation port will make it a contract: a stream of the run's events,
and a published shape for the state they fold into. The run's own page
becomes one consumer of it, and a view built against the shape keeps
working when that page changes.
