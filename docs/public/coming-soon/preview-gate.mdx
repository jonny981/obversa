<Note>
**Coming soon.** Not in this release. This page says what the feature is,
so that the shape is public before the code is.
</Note>

A callback gate asks a person a question and waits. What it can show is
what the run wrote: a diff, a file, a summary. For a change to something a
person would normally look at, that's the wrong evidence. The evidence is
the thing itself.

This gate keeps the built thing running and opens a link to it, so the
question arrives with the running software, not a description of it. The
person looks at it from a phone, and the answer goes back into the run
that's waiting for it.

See [A person decides](/workflows/approval).
