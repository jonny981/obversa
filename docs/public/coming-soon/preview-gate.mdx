**Coming soon.** Not in this release. This page says what the feature is,
so that the shape is public before the code is.
</Note>

Show a person the running software, not a description of it, and take
their answer back into the run. A [callback gate](/reviewing/callback-gates)
today can show what the run wrote: a diff, a file, a summary. For a change
to something a person would normally look at, the evidence is the thing
itself.

This gate will keep the built thing running and open a link to it, so the
question arrives with the software behind it. The person looks at it from a
phone, decides, and the answer goes back into the run that is waiting for
it, the same way any callback answer does.
