**Coming soon.** Not in this release. This page says what the feature is,
so that the shape is public before the code is.
</Note>

A person gate asks a question and waits. What it can show today
is what the run wrote: a diff, a file, a summary. For a change to something
a person would normally look at, that is the wrong evidence. The evidence
is the thing itself.

This gate holds the built thing running and opens a link to it, so the
question arrives with the software attached rather than with a description
of it. The person looks at the running thing, from a phone, and the answer
goes back into the run that is waiting for it.

See [A person decides](/workflows/approval).
