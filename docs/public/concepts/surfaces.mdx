A surface is a small user interface for one decision. A diff review with
inline comments is a surface. A visual approval is a surface. A structured
form is a surface.

Surfaces appear when they are necessary. They close after the decision. The
right surface appears for the situation. Your workspace stays a terminal.

## Surfacer

Surfacer is the package that runs surfaces. It does three things:

- It runs a secure local server session for one surface.
- It places the surface in a pane of your host. cmux is the first host
  adapter. A normal browser is the fallback.
- It returns one opaque result to its caller.

Surfacer owns no gate state, no routing, and no run records. It only shows
an interface and returns the result.

## Your host stays yours

Obversa does not ship a window manager. Your multiplexer supplies the panes.
Surfacer plugs into the host through a small adapter.

This is a deliberate limit. The market has many good terminal hosts. You keep
your choice, your layout, and your keybindings. Obversa supplies the
surfaces, not the shell.

## Security

A surface session binds to one loopback port with one session token. Each
request must carry the token. The session accepts bounded requests only. The
server stops when the surface closes.
