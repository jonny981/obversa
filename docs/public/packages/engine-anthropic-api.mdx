---
title: "Anthropic API Engine"
description: "@obversa/engine-anthropic-api runs engine requests directly through the Anthropic Messages API."
---

`@obversa/engine-anthropic-api` is an engine plugin that calls the Anthropic Messages API directly. It streams tokens as they arrive and starts no command-line process.

## Requirements

- An Anthropic API key, in the `ANTHROPIC_API_KEY` environment variable or the `apiKey` option

## Install

```bash
npm install @obversa/obversa
```

## Identity

The plugin reports `provider: 'anthropic'`. It runs the model the request names. Without one it uses `defaultModel`, and without that `claude-haiku-4-5-20251001`.

## Usage

```ts
import { AnthropicApiEngine } from '@obversa/engine-anthropic-api';

const engine = new AnthropicApiEngine({
  defaultModel: 'claude-haiku-4-5-20251001',
  apiKey: process.env.ANTHROPIC_API_KEY,
});
```

## Limits

- It takes text-only requests. A request that asks for tools or workspace access fails as `invalid-config`.
- It ignores `AgentRequest.env`, because there's no process to pass it to.
- Server errors (HTTP 5xx) and connection errors, including timeouts, are
  retried. A rate limit (HTTP 429) fails as a `rate-limit` error, carrying the
  API's `retry-after` wait when it sends one.
