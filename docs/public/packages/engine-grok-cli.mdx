title: "Grok CLI Engine"
description: "@obversa/engine-grok-cli runs isolated engine attempts through a fresh Grok CLI process."
---

`@obversa/engine-grok-cli` is an engine plugin that runs one isolated engine attempt through the `grok` command-line tool.

## Requirements

- Grok CLI 1.0.5
- Grok credentials, passed in the `environment` or `authFile` option

## Install

```bash
npm install @obversa/obversa
```

## Identity

You name the provider and model family in the `identity` option, such as `{ provider: 'xai', modelFamily: 'grok-4' }`. The plugin records them as given.

## Usage

```ts
import { GrokCliEngine } from '@obversa/engine-grok-cli';

const engine = new GrokCliEngine({
  executable: '/absolute/path/to/grok',
  version: '1.0.5',
  identity: { provider: 'xai', modelFamily: 'grok-4' },
  permissionMode: 'dontAsk',
});
```

## Limits

- `executable` must be an absolute path.
- Before its first attempt, the engine runs `grok --version` and refuses to run
  if the version differs from `version`.
- Each attempt gets its own temporary home directory, with only the tools and
  permissions the request declares.
