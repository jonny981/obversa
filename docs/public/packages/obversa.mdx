`@obversa/obversa` is the bundle: one dependency that installs every public
package except the Jev engine, so a project gets the runtime, the runner,
the contracts, the process tools, the ready-made workflows, the surfaces,
the memory adapters, webhook notifications and the engine adapters at once.
It has no API of its own; import each tool from its own package.

## Install

<CodeGroup>

```bash npm
npm install @obversa/obversa
```

```bash pnpm
pnpm add @obversa/obversa
```

</CodeGroup>

The install adds one dependency to your project:

```json package.json
{
  "dependencies": {
    "@obversa/obversa": "^0.1.0"
  }
}
```

## Quickstart

After the bundle is installed, import from the member package you need. The
smallest run imports two names from the runtime:

```ts examples/one-agent-job.ts (excerpt) {1-2}
import { agentJob, run } from '@obversa/runtime';
import { MockEngine } from '@obversa/runtime/testing';

const engine = new MockEngine(() => 'ready');
```

Every package on the [API reference](/packages) page says "Included in
`@obversa/obversa`" where the bundle installs it, so you can also install
any one of them on its own.

## Jev is separate

The [Jev API Engine](/packages/engine-jev-api) isn't in the bundle. It
needs its own endpoint and key, so install it when you use it:

```bash Terminal
npm install @obversa/engine-jev-api
```
