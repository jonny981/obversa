---
title: "@obversa/obversa"
description: "Install the bundled Obversa packages with one dependency."
---

`@obversa/obversa` installs these packages together: the runtime, the
runner, the shared contracts, the process tools, the ready-made workflows,
the surfaces, the memory adapters, webhook notifications and every engine
adapter except Jev.

```bash
npm install @obversa/obversa
```

The install adds one dependency to your project:

```json
{
  "dependencies": {
    "@obversa/obversa": "^0.1.0"
  }
}
```

Install [Jev](/packages/engine-jev-api) separately:

```bash
npm install @obversa/engine-jev-api
```

The bundle has no API of its own. Import each tool from its own package. You
can also install any package on its own, without the bundle.

The package table on the [docs home page](/) lists every public package,
Jev included.
