---
title: "OpenCode CLI Engine"
description: "@obversa/engine-opencode-cli runs isolated engine attempts through a fresh OpenCode CLI process."
---

`@obversa/engine-opencode-cli` is an engine plugin that runs one isolated engine attempt through the `opencode` command-line tool. It manages permissions, tools, and structured results for the attempt.

## Requirements

- Node.js 22.12 or later
- OpenCode CLI 1.18.23
- Host-selected authentication

## Install

```bash
npm install @obversa/obversa
```

## Identity

The plugin reports the provider and the model family of the model each
request names, read from the `provider/model` string through the one
derivation every harness that runs other providers' models shares.
`anthropic/claude-sonnet-4-5` is reported as provider `anthropic` and
model family `claude`. The identity given to the constructor is a claim
about what the instance serves: a request whose model disagrees with it
is refused before anything runs.

## Usage

```ts
import { OpenCodeCliEngine } from '@obversa/engine-opencode-cli';

const engine = new OpenCodeCliEngine({
  executable: '/absolute/path/to/opencode',
  version: '1.18.23',
  identity: { provider: 'anthropic', modelFamily: 'claude' },
});
```

## Limits

- The plugin requires an absolute path to the OpenCode executable.
- The executable must match supported version `1.18.23`.
- Structured outputs require the model to emit the expected result marker format.
- `managedConfigDirectories` names extra directories the managed-config check reads beyond the real system paths; a caller passes them deliberately, and the check refuses to run when any of those directories holds a managed config file.
