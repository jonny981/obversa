`@obversa/engine-claude-agent-sdk` is an engine plugin that runs requests through the Claude Agent SDK. Each request is a fresh SDK `query()` call, so every step starts with a clean context.

## Requirements

- Claude Code signed in on the machine that runs the engine

## Install

```bash
npm install @obversa/obversa
```

## Identity

The plugin reports `provider: 'anthropic'`. It runs the model the request names, or `defaultModel` when the request names none.

## Usage

```ts
import { AgentSdkEngine } from '@obversa/engine-claude-agent-sdk';

const engine = new AgentSdkEngine({
  defaultModel: 'claude-sonnet-4-5',
});
```

To give the agent memory, pass any adapter that implements the `Memory` contract from `@obversa/api` to the constructor:

```ts
import { AgentSdkEngine } from '@obversa/engine-claude-agent-sdk';
import { openGitMemory } from '@obversa/memory-git';

const memory = await openGitMemory({
  repositoryPath: process.cwd(),
  scope: 'run-1',
});

const engine = new AgentSdkEngine({
  defaultModel: 'claude-sonnet-4-5',
  memory,
});
```

## Limits

- The plugin has no API key option.
- Memory reaches Claude as an MCP tool.
- In the `read` workspace mode, Claude gets only the `Read`, `Grep` and `Glob`
  tools the request names. In the `none` mode it gets no tools. Both modes block
  `Bash`, `Edit`, `Write`, the sub-agent tools and every MCP tool. A settings
  file outside the run can't restore them.
